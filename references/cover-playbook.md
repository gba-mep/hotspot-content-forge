# 小红书封面方法论 v2（四平台爆款拆解蒸馏·公开版）

> 公开版（v0.2.0）。完整版式细节见仓库 SKILL.md。

配套主线：真场景照片打底 + 护眼浅色配色是两条既定红线，本篇在其之上补充构图与排版规律。

## 一、四个通用自检（出图后必做，不合格重做）
1. **3秒测试**：缩到手机缩略图大小（200px 宽），3秒内能看清核心信息吗
2. **遮盖测试**：遮住文字画面能独立传题；遮住画面文字能独立卖点——两者须居其一强
3. **平台对比**：与同领域热门封面并排，信息密度/风格有没有竞争力
4. **遮挡区检查**：文字避开底部（被标题栏挡）和右上（被平台图标挡），集中不分散

## 二、六大构图模板（按内容类型选，沉淀成系列视觉）
| 模板 | 结构 | 适用 |
|---|---|---|
| A 对比型 | 左右/上下：痛点vs爽点，Before/After | 测评/翻车/改造，CTR 最高的类型 |
| B 人像+气泡 | 人物出镜+扎心/专业话语标签 | 情绪/人设（夸张表情比无人脸 CTR 明显更高）；气泡不得压住人脸，对话冲突用「AI说→我说」双气泡最自然 |
| C 清单合集 | 多物拼图+编号+数字 | 合集收藏向（干货篇） |
| D 截图+红圈 | 实拍截图+手绘感红圈/箭头 | 教程/实测（工具类，圈出重点） |
| E 大字报 | 纯/浅底+超大利益点大字 | 观点/悬念（一图一句） |
| F 真场景+文字卡 | 实拍照片打底+奶白/鹅黄信息卡 | 默认推荐骨架 |

- **大字报策略**：高级底色保留当质感，但文字版面占比必须 ≥40%，主体降为配角；钩子用**两段冲突金句同大字号**（如「领导以为我在卷」/「其实我让AI干了全部的活」），主标题字号 112 + 副句 88 起步——副句用默认列表字号（48）会被主体吞掉、钩子力度腰斩；艺术展式高级封面只在情绪向调剂用，硬核工具类主线一律大字报。缩略图自检：主句在 200px 宽下依然逐字可读
- 爆款账号封面都**系列化**（固定构图+换内容），提升信息流辨识度——推荐固定 F 为骨架，钩子区在 A/D 间轮换
- 构图法：主体居中或黄金分割点；对比制造强冲突（正确/错误、平价/贵价）
- 封面背景必须与笔记主题同类，不串台；新素材流程：直链下载→尺寸校验→视觉验场景→登记清单

## 三、文字层级（铁律）
- 封面字 ≠ 笔记标题：更短更冲，**主标题≤8字**，副标题字号明显更小；一个封面只讲一个核心点
- 主标题粗体高对比+描边阴影；**必须有数字**（3步/92%/53%/7天）
- 信任词替代弱化词：「已验证/实测有效」替代「免费/限时」
- 手绘感红圈/箭头圈重点；emoji（⚠️✅❌）辅助视觉跳跃（图内文字仍禁 emoji 字形，用图形元素替代）
- 人物封面：标题占画面高五分之一到四分之一；人物占60%时眼睛在上三分之一

## 四、高级感结构化编码（出图前必读）
**思路：放弃纯色/渐变素材，改用「顶尖设计师人设 + 七段结构化英文 Prompt」让 AI 生图（Pollinations/flux 免费通道）**

### 视觉 VI 宪法（建议固化为 System Prompt）
账号人设示例：工程/科技 AI 自动化方向。铁律：
- 七段式：极简工程/科技隐喻（哑光金属 CAD 卷轴、悬浮半透明代码方块、微距齿轮）；左侧留 40% 纯净背景给文字；水泥灰/深空黑/纯净白主色，禁渐变、禁大面积深蓝/大红/高亮黄/亮绿；唯一点缀色≤10%画面：科技类=极客青、工程类=安全帽黄、数据类=墨绿；磨砂玻璃/哑光金属/顶光/微噪点；--ar 3:4。
- 文字必须代码叠加（PIL）：Kicker 左上带系列编号；大标题极粗断层；列表严格左对齐+—；Hook 距底 8%+极细点缀色分割线，代码里 assert 强制≤14字；深底纯白字/浅底深灰字。
- 严禁高饱和、贴纸堆砌、非管线封面；文字绝不压主体。
- 例外模组【Tech-Launch 科技发布会】：允许霓虹发光/高对比/撞色——3D isometric+悬浮UI卡片+虚线连接+半透明亚克力+数据图表元素；四色模式（A 深空黑绿底+荧光青绿发光｜B 暗夜紫底+纯白亚克力｜C 纯黑底+高饱和撞色｜D 亮白淡紫底+紫亚克力，信息流里亮底反而更跳）。另备**纯文字零生图版 TypoLaunch**（数字高亮块/三列编号/渐变slogan/半调网点底，无主体漂移风险，高确定性兜底）。适合数据页/功能发布/测评对比类。

### 画质增强与后处理
- 生图请求 1152×1536 原生大图，严禁小图后期拉伸；Quality 段追加：`extreme clarity, sharp edges, 16k, shot on Hasselblad H6D-100c, hyper-detailed, realistic textures, no blur`。
- PIL 后处理三连击：裁水印8% → LANCZOS 高保真缩放 → Sharpness(1.5) 锐化 → Contrast(1.05) 微对比；最后合成完加 2% 高斯胶片噪点（film grain）掩盖 AI 涂抹感。新产图一律 grain 收尾。

### 生图 Prompt 七段结构（英文）
① Subject 明确主体 ② Layout（minimalist, negative space, Swiss grid, asymmetrical balance, golden ratio）③ Color（low saturation, Morandi/monochromatic + single accent）④ Typography（排版由代码叠加，生图端写 no text）⑤ Texture & Lighting（frosted glass/matte metal/film grain, soft diffused studio light）⑥ Style（hyper-realistic 3D render / flat illustration）⑦ Quality（8k, octane, masterpiece）

出图接口：`https://image.pollinations.ai/prompt/<urlencoded>?width=1152&height=1536&nologo=true&seed=N&model=flux`；免费档限速 1张/分钟、右下角水印 → PIL 裁底部 8%；中文文字全部代码叠加（generous tracking=逐字插空格，字号层级断层）。

### 喻体词库（通用建议）
- flux 渲不出抽象喻体（天平/倾斜之类多写几遍也出不来）——主体选简单具体物件（球/方块/筹码堆/底座），隐喻靠组合表达；换喻体比改写同一喻体快。建议对每个喻体记录 ✅验证成功/❌不可用，如天平类禁用。
- 出图先视觉验主体对不对题再叠字；402/503 用 30-35s 退避重试，不是永久失败。
- 主体漂移判定：在 VI 体系里情绪与构图留白优先于具象物体——只要情绪对、构图干净（留白/色调达标），直接标记可用，不追具象重跑 seed；仅当色调或构图破功才重出。

### 五维度速记
①架构=留白克制 ②色彩=低饱和+单点缀 ③排版=层级断层+宽字距 ④材质=磨砂/哑光/噪点+柔光 ⑤风格=按题材路由

### 出图四指标验收（视觉模型）
1. 颜色≤3种？2. 文字克制有呼吸感？3. 材质有反光/纹理过渡（非塑料平涂）？4. 单一主体焦点？不合格→具体化修正 Prompt（more negative space / reduce saturation）重出
- TypoLaunch 纯文字版另查：slogan 左溢出（居中锚宽度超画布）、右侧裁切（slogan 过长会静默切尾——先缩短文案再重渲染，别改字号硬塞）、高亮块与同行文字基线、三列分隔线与文字间距
- 系列 Kicker 色 DNA 锁死不可按底图变色：深黑底+黄栏头+青反光这类跨点缀色撞色正是信息流视觉焦点；Kicker/细线永远用系列绑定色

### 突发热点三件套
大厂人事/财报/发布突发时：TypoLaunch 封面（剧情钩子+高亮块关键词）+ 图表数据页 + 时间线页；数据只用公开财报/官方口径，钩子用开放式提问，产完即发勿拖——热点热度半天就过。

## 五、配色对比（与护眼浅色规范协调）
- 【2025-2026 趋势】多巴胺公式：70%中性+30%高饱和（经验值：点击率显著提升）；年度色 Pantone 云舞白/WGSN 变革青；在火风格 Y2K铬银雾紫·Frutiger Aero水色·颗粒渐变·新粗野；已嫌：AI默认风
- 对比原则：明度差>50%，深底浅字/浅底深字+描边；禁相近色
- 护眼落地：奶白/抹茶浅底 + 墨绿深字（对浅底即满足对比），强调用低饱和鹅黄块
- 原生感=信任：手机实拍、无滤镜感、生活化场景；过度精修会被大脑当广告过滤掉

## 七、数据阈值与迭代（看数据顺序）
点击率→完读率→收藏率→评论质量→转粉率；图文 **CTR<2.5% 改封面标题**；完读<40% 改开头钩子；收藏<5% 干货不足；评论权重4分/转发4分/关注8分（最高）——封面为评论引导留钩子
- **A/B测试**：同选题做两张侧重点不同的封面（如一张人脸对比一张硬核过程），CTR 高者主推；CTR 不达标时下一期 Prompt 预埋对冲（high contrast, dramatic shadow），直接做成 A/B 双版（同一主体两版底色/点缀，系列 Kicker 不变）
- 发布后观测节点：+24h / +72h，按本节阈值出「留 / 换封面 / 改标题」三选一明确诊断，不给模糊建议
- **每周拆解 top50** 同领域高 CTR 封面（颜色布局/字号/关键词），回填本篇

## 八、PIL 出图脚本坑（写生成脚本前先读）
- **中文字体锁定 Noto Sans CJK Bold，且 .ttc 必须 index=2（SC简体面）**：用 glob 找字体会先捡到 SerifCJK（衬线）——封面网感全无；日文面（index 默认0）骨架变形。写法：`ImageFont.truetype('/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc', sz, index=2)`
- **NotoSansCJK 无 emoji/勾叉字形（⚠️✅✓👉全变豆腐块）**——用纯文本符号替代：→、√、X，或 PIL 自绘图形；写完脚本先跑一遍全部字面字符串确认无 emoji 再出图
- **底卡列表+底部标签页（清单/收藏页）给呼吸位**：卡片总高度收在距底标签 ≥60px 以上，否则最后一张卡被标签压住——自检必查「最后一项完整」
- **奶油黄底 (255,225,130)+黑字**（低饱和奶黄，非正黄，实测不刺眼）可作网感主色——大字报白描边贴纸字技法：同文字四向偏移画白描边层再叠黑字；与护眼灰绿底轮换使用，同周不连用
- 背景图先 resize+crop 到目标画布尺寸再画坐标——把 1080×1440 的底图直接当 1242×1660 的画布用，所有越界坐标会被静默裁掉；保存后用 PIL 读回 size 复核
- 局部半透明叠加用 `paste(layer, pos, layer)` 带 mask；`alpha_composite` 要求两张图完全同尺寸，尺寸不一致直接报错——整幅叠加才用 alpha_composite
- paste 的坐标必须 int（除法产生的 float 会 TypeError）；多脚本共用 helper 时把取整收进函数里
- 文字换行用 `d.textlength(同字号字体)` 逐字累积断行——换行量宽和绘制字体不一致时，行宽算错照样出界；双栏布局右栏文字以右栏中心为锚（anchor="mm"），别沿用左栏 x 坐标
- 生图 Prompt 里写死留白位置（如 negative space in the upper half），文字只叠在留白半区；文字压到主体上就在验收环节打回
- 自检截图若与上一版雷同，先怀疑视觉模型按路径缓存了旧图：复制成新文件名再验

## 九、风格模组（公开通用做法）
### Style C：Brutalist-Terminal 粗野终端风
- 用途：代码跑通/报错解决/避坑实录。纯 PIL 零生图，无主体漂移风险。
- 结构：黑底微噪点 → mac 终端窗口栏（红黄绿灯）→ 代码块包裹标题（`# 标题` 荧光绿）→ 等宽代码行 → 分隔线 → 输出行语义色：red=报错、green=修复、dim=注释/过程。
- 坑：服务器常只有 DejaVuSansMono-Bold.ttf（无普通版）；中英文混排行中文自动回退 Noto 常规体，别给整行配 mono。

### Style D：Cinematic-Narrative 职场纪实情绪风
- 用途：摸鱼/老板/裁员/情绪共鸣。真实感>精美：过度精修会被当广告过滤。
- 流程：职场实拍选图 → 压暗（亮度 0.36-0.55）+微对比 → 半透明黑卡或底部压黑区（RGBA paste 带 mask）→ 白字大标+绿色语义强调 → 荧光笔批注。
- 荧光笔批注（无手写字体的替代方案）：黄底圆角块 (255,244,120,~110)+深色文字，`layer.rotate(±1-2°, expand=True)` 后带 mask paste，微斜贴感即成；文字长度必须按 textbbox 量宽后留出旋转余量，右溢出会被画布裁掉。
- 监控/职场惊悚题材可加 OSD 层：REC 红点 + 实时时间戳 + CAM 编号 + 四角取景框，真实感拉满且不依赖生图。
- 题材竞品注意：同质化>30% 换题，情绪向与干货向间隔发布。

## 十、发布合规钩子（公开通用）
- 合规句式推荐三类：开放式提问（「你们最头疼哪一步？评论区聊聊」）/ 主页承接（「主页有更多拆解」）/ 置顶评论自取（「已放在置顶评论，自取」）。
- 硬禁：评论区扣字/点赞关注交换/私信发资料/互赞互关抽奖；关键词拦截拦不住擦边变体，产稿层需自查变体并改写。

## 十一、实测经验（泛化结论）
- 翻车叙事封面（真场景+数字反差）是历史最佳基因（如「让 AI 操作工具」这类演示案例）
- 纯色块+文字封面 = 点击失败，已废止
- 改封面窗口：发布后 24h 内改 2-3 次安全
- 旧笔记数据不达标时按本文模板逐张翻新封面：逐张对题选真场景照片+钩子模板，不要共用一套文案硬套——人群词/钩子/利益数字逐张传参
