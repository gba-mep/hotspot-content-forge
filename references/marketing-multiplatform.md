# 营销推广与多平台文案改写要点（脱敏公开版）

> 本文只保留可公开的平台规则要点、发布清单与各平台风格差异，不包含任何具体产品、项目或用户数据。

## 第一节：营销推广要点

### 1.1 小红书平台规则

- **严禁站外导流**：二维码、外链、提及其他平台账号、谐音缩写导流都在打击范围——笔记、图片、评论、简介全覆盖，违规限流封号。合规做法：引导站内私信、主页合集。
- **违禁词**：最、第一、国家级、全网最低价、独家优惠等极限词不可用；可用「限时福利」「粉丝专享」等替代。医疗、金融、法律类内容无资质不能输出建议。
- **封面**：3:4 竖图占地最大；禁止「震惊体」诱导文案（不看后悔 / 内部消息）。真人出镜 > 产品特写 > 纯文字；对比图、步骤图更能提升可信度。
- **标题公式**：痛点 + 解决方案；关键词在标题与正文首段自然出现，不堆砌；前 3 个 tag 用核心关键词，后面加场景词；相关 tag ≥3 个。
- **正文**：100–200 字，务必分段；笔记发出后观察 3 小时自然流量再决定是否改封面 / 标题（改动 2–3 次内安全）。
- **流量机制**：推荐 + 搜索各半；先进入小流量池，点赞 / 收藏 / 评论 / 转发数据好则进入更大池。发布 1 小时内引导 3 条以上评论（无评论不买单）。
- **刷量 = 违规**：不刷赞、不互赞、不脚本批量发布。

### 1.2 图文物料制作规范

- 尺寸建议 1242×1660（3:4）；首图 = 大标题钩子 + 产品示意 + 4 条卖点框；第 2 图功能清单；第 3 图场景卡片；可加一张轻量动图（帧数与体积控制在平台可接受范围）。
- **物料内容必须与产品当前版本一致**：功能下线后物料要同步更新，避免宣传已删除的功能。
- 绘图工具实践：中文字体使用完整字体文件路径；emoji 在部分渲染环境下会显示为方框，慎用；圆角矩形 + 描边框 + 留白是最低美学保障；每张图完成后需逐张目检重叠 / 错别字后才算成品。

### 1.3 产品设计美观原则（通用）

- 深色主题：中性分层底色（不用纯黑）+ 一个高质感强调色（祖母绿 / 蓝宝石 / 紫水晶 / 珊瑚锈类），强调色用量控制在约 10%；浅色主题：奶油白而非惨白 + 赤陶 / 叶绿点缀，强调色比深色版深一到两档。全低饱和灰调容易显得发闷。
- 对比度按 WCAG ≥4.5 程序化断言 + 色卡预览目检，不要只靠肉眼。
- 情绪价值是功能：趣味文案与轻度紧张感（如涨跌色）可以作为产品体验的一部分。
- 每个新功能必须有按钮入口，永不藏在配置文件里。

### 1.4 发布检查清单

1. 物料与产品版本一致？
2. 全文扫违禁词？
3. 无任何导流信息？
4. ≥3 个相关 tag？
5. 正文分段且 ≤200 字？
6. 图片逐张目检通过？
7. 首图 3 秒内看懂卖点？

### 1.5 用户粘度设计（留存四件套）

粘度 = 每天有开的理由 + 有晒的素材 + 舍不得删的数据。

- **连胜打卡**：每天首次使用播报「连续第 N 天」，断签归零——损失厌恶是留存第一杠杆；周报中同步展示。
- **进度播报**：按阶梯提醒当日进度，每天不超过 4 次，避免打扰；利用蔡格尼克效应（未完成的事更被记住）。
- **定时自动报告**：固定每周同一时段自动弹出上周总结，每周一次，用状态标志防重复。
- **累计里程碑**：跨天累计成就（连胜天数 / 累计次数 / 累计金额），达成时永久记录——时间久了用户删的不是程序而是自己的记录。
- **文案轮换池**：每日不同的趣味文案是最便宜的日回访钩子，池子建议 ≥30 条；分享图 / 海报的配色与金句每次生成随机抽取（按日期取模等于每天固定，用户会腻）。

### 1.6 选品方法论

- 验证过的爆款公式：极小切口 + 情绪价值 + AI 重做一遍 + 小红书「听劝式开发」。
- 红海勿入：习惯打卡、待办、记账类；纯广告变现基本不可行。
- 可行变现路径：免费引流 + Pro 买断小额定价 + 内容飞轮（免费产品矩阵 + 自媒体）。
- 听劝式开发 SOP：先发求建议笔记 → 评论区即需求池 → 版本历史写用户建议 → 用户自发晒图形成 UGC 飞轮。

### 1.7 钩子文案公式

1. 首句数字反差：把抽象量换算成意外的小单位，3 秒留人。
2. 具体化损失：给时间标价，制造痛感。
3. 写「使用后症状」而不是功能清单：UGC 感强，评论区有得聊。
4. 第三方证言替代自夸（同事 / 网友反馈）。
5. 听劝收尾：点名 2–3 个候选下一条内容，让评论区投票——评论区即需求池。

### 1.8 交付流程（SOP）

查最新平台规则 → 按规范生成物料 → 逐张目检 → 发布清单过一遍 → 交付图 + 建议发布文案 + tag。产品优化需求先过粘度框架再动手。导出 / 分享功能在无图像库环境下给出「一键保存」的可用格式，不写「请自行截图」这类提示语。

## 第二节：多平台文案改写（风格差异表）

### 2.1 支持平台与别名

| 平台 | 可识别别名 |
|------|-----------|
| 公众号 | 公众号、微信公众号 |
| 视频号 | 视频号、微信视频号 |
| 抖音 | 抖音、dy |
| 快手 | 快手、ks |
| 哔站（B站） | 哔站、B站、bilibili、哔哩哔哩 |
| 小红书 | 小红书、红书、xhs |
| 知乎 | 知乎、zhihu |

输入约定：`[平台1 平台2 ...] [文案内容]`，支持空格或逗号分隔多平台；关键词「全部 / all / 所有」触发全平台模式。未识别到平台关键词时应主动询问目标平台。

### 2.2 七大平台风格特征与改写要点

| 平台 | 风格特征 | 改写要点 |
|------|---------|---------|
| 公众号 | 知识性、实用性为主；排版干净简洁；图文并茂；语气亲和；常用指南 / 教程 / 解析 / 秘籍 / 经验分享 / 案例 / 趋势等关键词 | 口语化复述，段落结构与原文保持一致；正文携带 2–3 个公众号风格关键词；Markdown 结构化输出 |
| 视频号 | 生活化记录；互动性强；简短直接；情感共鸣；常用网络热词；强调价值实用；促销福利；故事性 | 保持段落结构；口语化表达；鼓励点赞评论分享的自然引导 |
| 抖音 | 流行网络热词（yyds、绝绝子、打卡、种草等）；简短有力；互动性强；情感共鸣；幽默夸张；生活化；励志正能量 | 简短口语化；制造互动钩子（评论区提问）；语气积极 |
| 快手 | 接地气、通俗易懂；互动性强；幽默风趣；情感共鸣；促销秒杀类词汇；热词（安排上了、奥利给等）；夸张表达；短小精悍 | 直击主题，句子短；称呼亲切（兄弟姐妹们风格）；促销类可用限时/秒杀话术（注意平台违禁词） |
| 哔站（B站） | 二次元 / 宅文化词汇（萌、萌新、次元壁等）；弹幕文化；圈内热词（真香、打call、666）；幽默自嘲；游戏电竞术语；干货教程导向；夸张戏剧化 | 融入圈内用语与弹幕互动引导；知识类内容强调干货浓度；保留个性与创意表达 |
| 小红书 | 多 emoji（至少 5 个不重复）；爆款关键词（好用到哭、小白必看、宝藏、手把手、吐血整理、家人们、建议收藏等）；二极管标题法（正面刺激：产品+只需1秒+便可开挂；负面刺激：你不XXX+绝对会后悔）；痛点+悬念 | 标题和每个段落含 emoji；口语化拉近读者距离；末尾附加 `#关键词` 形式的 tags，与内容强相关并蹭高热度话题 |
| 知乎 | 独特观点、专业性、深度；语言优美流畅；结构清晰；数据与实例支撑；简明扼要；适度幽默；常用关键词（大佬、知友、高赞、科普、内行、不喜勿喷等） | 直接回应问题；正文携带 2–3 个知乎风格关键词；用标题、列表、引用组织内容增强可读性 |

### 2.3 通用改写规则

1. 站在文案发起者的角度改写，段落结构与原文保持一致。
2. 全部以口语化表达方式重新复述。
3. 输出格式：按平台逐条列出（序号 + 平台名 + 改写全文），各平台之间用分割线隔开；小红书条目末尾附加 tags。
4. 输出后不追加平台间差异点评，也不再追问是否需要调整。

### 2.4 典型使用场景

- **矩阵号内容分发**：一篇核心文案一键改写为七平台版本，批量分发。
- **跨平台 A/B 测试**：同一文案在不同平台风格下对比呈现效果。
- **平台特定优化**：为投放目标平台生成符合调性的差异化文案。
- **新平台快速适应**：将熟悉平台的文案改写为新平台风格，快速掌握调性。
